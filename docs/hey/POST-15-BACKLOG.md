# HEY — AFTER THE 15 PARTS

**Decision (owner, 20 October 2026):** everything newly planned — the possibility research, the inventions, the extra capability ideas — is built **after** the 15-part program completes. It does not enter Parts 1–15.

**Why this matters:** the 15 parts are about making HEY *work and be honest*. The new ideas are about making it *bigger*. Mixing them is how a foundation project turns into another month of nothing shipping.

---

## Phase A — THE 15 PARTS (current)

Foundation, architecture, models, agents, evolution, memory, answers, creation, devices, automation, UX, business, security.

**Rule:** no part may pull a new idea forward. If a part discovers a need, it records a Vault proposal and continues.

## Ordering rule for Phase B

Not by excitement. By this order:

1. Anything required to **sell** the Leaders pilot (Teacher Time Ledger, print pipeline, trilingual, curriculum pack).
2. Anything required to **install** it (portable exe, auto-update, offline).
3. Anything that **reduces cost** (Instinct router, escalation ladder, cost meter).
4. Anything that **increases trust** (Action Vault, memory review, egress ledger).
5. Everything else.

## Gate for Phase B

Each item enters through the Capability Vault built in Part 5, with:

- kill criteria pre-registered,
- a machine-readable change plan,
- an owner decision (Sako or Amad),
- and a test that would fail if it stopped working.

No item skips the Vault because it is "obviously good".
