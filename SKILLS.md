# HEY Skill Catalog

HEY skills are production-grade integrations with industry-standard frameworks. Catalog regenerated from canonical skill repositories:

## mem0ai/mem0
Memory layer with semantic embeddings and automatic consolidation. Mem0 provides long-term memory with deduplication, relevance scoring, and graph-based relationships. Used for persistent user knowledge, conversation context retention, and cross-session recall.

## letta-ai/letta
Agentic memory architecture with persistent state and tool use. Letta enables agents to maintain structured beliefs, recall past interactions, and execute tools with memory-aware planning. Integrated for agent memory persistence and reasoning continuity.

## microsoft/autogen
Multi-agent conversation frameworks with structured messaging. AutoGen provides agent-to-agent communication patterns, role-based interactions, and dynamic task delegation. Used for council topologies and collaborative reasoning.

## langchain-ai/langgraph
Stateful, multi-step agent workflows with graph orchestration. LangGraph provides deterministic control flow, checkpointing, and human-in-the-loop patterns. Powers HEY's deliberation pipelines and workflow engine.

## crewAIInc/crewAI
Role-based multi-agent collaboration with manager-worker patterns. CrewAI enables specialized agents to work together toward a common goal with defined roles, tools, and workflows. Used for team formation and task delegation.

## BerriAI/litellm
Unified LLM provider gateway with cost control and routing. LiteLLM provides a single API for multiple providers, automatic failover, rate limiting, and token counting. HEY's provider gateway is built on LiteLLM patterns.

## getzep/zep
Memory and knowledge management with graph-based relationships. Zep provides conversation memory, semantic search, and knowledge graph construction. Used for Cosmos memory layer and relationship tracking.

## dair-ai/Prompt-Engineering-Guide
Comprehensive prompt engineering patterns and best practices. The guide provides reusable prompt templates, chain-of-thought patterns, and evaluation methodologies. Source material for HEY's prompt construction and agent instruction generation.
